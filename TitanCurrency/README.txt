Matcha's TitanCurrency fork - WoW 3.3.5

Requires Titan Panel. Close WoW and extract this ZIP into Interface\AddOns.
Keep the TitanCurrency folder name. Gold tracking is a separate optional addon.
Right-click Currency for tooltip/bar selections, icons, zero balances, sorting,
and Show all. Drag currency balances to reorder them. Settings save per character.
Default emblems: Frost, Triumph, Conquest, Valor, Heroism.
